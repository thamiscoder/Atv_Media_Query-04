# Atv Media Query 04

Projeto de página web estática desenvolvido como estudo do curso **HTML5 e CSS3 do Curso em Vídeo**, no **Módulo 04, Capítulo 25 - Media Queries e Breakpoints**.

O objetivo deste exercício é testar diferentes versões visuais de uma página de acordo com o tipo de dispositivo ou contexto de exibição, incluindo celular, tablet, desktop, TV e impressão.

## Sobre o projeto

O `mq004` é um estudo prático de **design responsivo com media queries**. A página utiliza a abordagem mobile first e troca imagens, ícones e estilos conforme a largura da tela ou o modo de impressão.

Na prática, o projeto mostra como uma mesma página pode se comportar de formas diferentes dependendo do ambiente em que é aberta.

## Funcionalidades estudadas

- Desenvolvimento com abordagem mobile first;
- Uso de media queries para diferentes tamanhos de tela;
- Criação de estilos específicos para impressão;
- Troca de imagem de fundo por breakpoint;
- Exibição de ícones diferentes por dispositivo;
- Organização dos estilos em CSS base e CSS responsivo;
- Aplicação de breakpoints para celular, tablet, desktop e telas grandes.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- Media Queries;
- Mobile First.

## Como visualizar o projeto

1. Baixe ou clone este repositório:

```bash
git clone https://github.com/thamiscoder/mq004.git
```

2. Acesse a pasta do projeto:

```bash
cd mq004
```

3. Abra o arquivo `index.html` no navegador.

Para testar o comportamento responsivo, use o modo de inspeção do navegador e altere a largura da tela. Também é possível testar a versão de impressão usando a opção de imprimir ou visualizar impressão do navegador.

## Objetivo de aprendizado

Este projeto foi criado para praticar:

- breakpoints;
- design responsivo;
- media queries para tela;
- media queries para impressão;
- adaptação visual por tipo de dispositivo;
- boas práticas iniciais de mobile first.
